Aplikacja desktopowa umożliwiająca konwersję plików pomiędzy formatami CSV, JSON, TXT, DOCX, ODT i PDF.

- Interfejs graficzny Tkinter
- Walidacja danych i obsługa błędów
- Testy jednostkowe
- Dokumentacja techniczna i raport testów
